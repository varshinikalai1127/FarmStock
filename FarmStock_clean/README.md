# FarmStock – Farmer's Produce Inventory Tracker

Spring Boot REST API for crops, harvest batches, sales, current stock and revenue.

## Main class
`com.example.farmstock.FarmStockApplication`

## Run
Open this folder in IntelliJ IDEA as a Maven project, reload Maven, and run `FarmStockApplication`.

## Database
Create database `farmstock`, then set your MySQL password in `src/main/resources/application.properties`.

## Port
8080
